If I were to write a book, here's where it would start and live.

> Writing a book is a horrible, exhausting struggle, like a long bout with some painful illness. One would never undertake such a thing if one were not driven on by some demon whom one can neither resist nor understand
> *— George Orwell*
{: .pull-quote}

It could be fun to have a space to work and play like this. The important part is that I keep working on it, and set up the site infrastructure to keep it organized as I add pages to the structure.

I don't know what it would be about yet.
{: .aside}

I'll want a different page layout, with a navigation specific to the book, but that can still reach the home page. Maybe the home page elements go to the footer navigation instead of in the header nav, and the header nav is just to get around the book, return to the previous chapter, go to the TOC, etc. Add previous and next and TOC links at the bottom of the page. As long as the pages are organized by chapter number (i.e. 01-chapter-one.md) it should organize well. But there could be an issue if I have an idea for another chapter to insert later on.
