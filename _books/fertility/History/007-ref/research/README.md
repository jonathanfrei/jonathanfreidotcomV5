# Chapter 7 research

One file per section. Each file is organized for drafting: what the section has to establish, a suggested order of evidence, then source cards.

**How to use a card**

- **Use for** — which beat of the argument.
- **Kind** — primary or secondary.
- **Cite / Link** — what goes in the citation list.
- **Claim** — the sentence the source actually supports.
- **Quote** — optional; copy from here rather than from memory.
- **Caveat** — do not overclaim.
- **Already in the book?** — if yes, cite and move; do not rebuild.

Do not treat X posts as sources unless the claim is that a public argument exists. They belong in the thought-experiment material, listed at the bottom of the relevant file.

Parent file: `../ref.md` (chapter contract and motion). These files replace the thin research notes in `ref.md` for drafting.
