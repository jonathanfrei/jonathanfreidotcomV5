Title: What Is Recursive Self-Improvement?
---

Recursive self-improvement is not simply a system getting better. It is a system changing the mechanism by which it gets better, so that the next iteration can potentially improve more effectively than the previous one.

The article should establish this as a general systems concept rather than an AI-specific phenomenon.

An examples is a programmer who fixes a bug versus the programmer who improves the testing system that finds and prevents bugs. The first improves the product. The second changes part of the mechanism that produces future improvements.

**First-order improvement:**

> The system changes its behavior or state in response to feedback.

**Recursive improvement:**

> The system changes the process, rules, representations, or capabilities through which it produces future improvements.

Not every feedback loop is recursive self-improvement, and not every adaptation that produces better outcomes necessarily improves the system's ability to improve itself.
